# Exhibits Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show sourced, concrete exhibits after a visitor submits their estimate, and on a standalone page, filed under the chain link each one bears on — so a reader can see which of their own beliefs the evidence touches.

**Architecture:** Content lives in `_data/exhibits.yml`. Jekyll reads it once and emits it twice: as JSON inside `index.html` for the result screen, and as static HTML at `/exhibits/`. No JavaScript builds the content; the script only chooses what to show and attaches the visitor's own numbers.

**Tech Stack:** Jekyll (Ruby 3.3) with `_data` YAML, vanilla JS inline in `index.html`, the existing token-driven CSS.

## Global Constraints

- Every exhibit carries a `limits` field. **An entry without one does not render** — this is what makes "exhibits, not predictions" structural rather than aspirational.
- Every claim is checked against a primary source: paper, system card, model card, or lab publication. Never press coverage.
- **This machine cannot extract text from PDFs** (no poppler / `pdftotext`). If a primary source is PDF-only and cannot be read, the exhibit is dropped rather than sourced to a summary. Confirmed-readable primaries: `metr.org` blog posts, `red.anthropic.com`, lab blog posts, arXiv HTML.
- Where a primary source contradicts the popular account, the exhibit reports the source and uses `limits` to name the gap.
- `link` is one of exactly `powerfulAi`, `dangerousBehavior`, `globalCatastrophe` — matching the `key` values in the `config` array in `index.html`.
- Dates state when the thing happened, not when it was reported.
- No change to the quiz, the sliders, or what is submitted. No exhibit interaction is recorded.
- No dark mode. The pages under `reports/` are not modified.
- Nav label is **Exhibits**, not "Evidence" — evidence implies proof, which is the claim being avoided.

- [ ] **Step 1: Write the validator first**

`scripts/check_exhibits.py`. This is the test — it is what enforces the constraint that an exhibit without `limits` never ships.

```python
#!/usr/bin/env python3
"""Validate _data/exhibits.yml.

`limits` is required on every exhibit: an exhibit that does not say what it fails
to establish is an anecdote, not evidence. Run before committing content.
"""
import re
import sys

REQUIRED = ("id", "link", "title", "date", "what", "source", "limits")
LINKS = {"powerfulAi", "dangerousBehavior", "globalCatastrophe"}


def parse(path):
    """Minimal reader for the flat list-of-maps shape this file uses, so the
    check has no dependency beyond the standard library."""
    entries, cur, key = [], None, None
    for raw in open(path):
        line = raw.rstrip("\n")
        if not line.strip() or line.lstrip().startswith("#"):
            continue
        if line.startswith("- "):
            if cur:
                entries.append(cur)
            cur, key = {}, None
            line = "  " + line[2:]
        m = re.match(r"^  (\w+):\s*(.*)$", line)
        if m:
            key, val = m.group(1), m.group(2).strip()
            cur[key] = val if val else {}
            continue
        m = re.match(r"^    (\w+):\s*(.*)$", line)
        if m and isinstance(cur.get(key), dict):
            cur[key][m.group(1)] = m.group(2).strip()
    if cur:
        entries.append(cur)
    return entries


def main():
    entries = parse("_data/exhibits.yml")
    errors = []
    seen = set()
    for i, e in enumerate(entries):
        where = e.get("id") or f"entry {i + 1}"
        for field in REQUIRED:
            if not e.get(field):
                errors.append(f"{where}: missing {field}")
        if e.get("link") and e["link"] not in LINKS:
            errors.append(f"{where}: link '{e['link']}' is not one of {sorted(LINKS)}")
        if e.get("id") in seen:
            errors.append(f"{where}: duplicate id")
        seen.add(e.get("id"))
        src = e.get("source")
        if isinstance(src, dict):
            if not src.get("url", "").startswith("http"):
                errors.append(f"{where}: source.url must be an absolute URL")
            if not src.get("label"):
                errors.append(f"{where}: source.label missing")
        elif "source" in REQUIRED and e.get("source") is not None:
            errors.append(f"{where}: source must have label and url")

    print(f"{len(entries)} exhibits, {len(errors)} problems")
    for err in errors:
        print("  " + err)
    by_link = {l: sum(1 for e in entries if e.get("link") == l) for l in sorted(LINKS)}
    print("by link:", by_link)
    return 1 if errors else 0


if __name__ == "__main__":
    sys.exit(main())
```

- [ ] **Step 3: Write the renderer**

Add above `setSubmissionStatus` in `index.html`:

```javascript
    // Shown only after a submission has landed, so the estimate is already fixed
    // and nothing here can influence the number that was recorded.
    const EXHIBIT_GROUPS = [
      { key: 'powerfulAi', label: 'P(powerful AI)' },
      { key: 'dangerousBehavior', label: 'P(dangerous behavior | powerful AI)' },
      { key: 'globalCatastrophe', label: 'P(global catastrophe | dangerous behavior)' }
    ];

    function loadExhibits() {
      const el = document.getElementById('exhibitsData');
      if (!el) return [];
      try {
        const parsed = JSON.parse(el.textContent);
        // An exhibit without `limits` does not render, here as on the page.
        return Array.isArray(parsed) ? parsed.filter(e => e && e.limits) : [];
      } catch (error) {
        console.warn('Unable to read exhibits', error);
        return [];
      }
    }

    function renderExhibits() {
      const host = document.getElementById('exhibitResult');
      if (!host) return;
      const exhibits = loadExhibits();
      if (!exhibits.length) return;

      const midpointFor = (key) => {
        const factor = (latestSnapshot && latestSnapshot.factors || []).find(f => f.key === key);
        return factor ? `${(factor.midpoint * 100).toFixed(1)}%` : null;
      };

      const escape = (text) => String(text).replace(/[&<>"]/g, c => (
        { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]
      ));

      host.innerHTML = `
        <h2 class="exhibit-result__head">What the evidence looks like</h2>
        <p class="exhibit-preamble">
          Exhibits, not predictions. Your estimate is already recorded — this changes nothing about it.
        </p>
        ${EXHIBIT_GROUPS.map((group) => {
          const items = exhibits.filter(e => e.link === group.key);
          const mine = midpointFor(group.key);
          return `
            <section class="exhibit-group">
              <h3 class="exhibit-group__head">
                ${escape(group.label)}${mine ? ` <span class="exhibit-group__mine">you put this at ${mine}</span>` : ''}
              </h3>
              ${group.key === 'globalCatastrophe' ? `
                <p class="exhibit-empty">Nothing has caused a global catastrophe. These measure routes, not outcomes.</p>` : ''}
              ${items.length ? items.map(e => `
                <article class="exhibit">
                  <h4 class="exhibit__title">${escape(e.title)}</h4>
                  <p class="exhibit__what">${escape(e.what)}</p>
                  <p class="exhibit__source">${escape(e.date)} &middot;
                    <a href="${escape(e.source.url)}" target="_blank" rel="noopener noreferrer">${escape(e.source.label)}</a>
                  </p>
                  <p class="exhibit__limits">${escape(e.limits)}</p>
                </article>`).join('') : '<p class="exhibit-empty">Nothing here yet.</p>'}
            </section>`;
        }).join('')}
        <p class="exhibit-result__more">
          The same collection lives at <a href="{{ '/exhibits/' | relative_url }}">Exhibits</a>.
        </p>`;
      host.hidden = false;
    }
```
